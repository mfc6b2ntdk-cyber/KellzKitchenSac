# KellzKitchenSac

Website for **Kellz Kitchen Jamaican Cuisine** — pickup and catering in Sacramento.

- Pickup: 5800 Madison Ave, Ste S, Sacramento, CA 95841
- Phone: (916) 220-4281
- Email: kellzkitchenjamaicancuisine@gmail.com

## Stack

React, TanStack Start, Vite, Tailwind CSS v4, TypeScript.

## Local

```bash
npm install
npm run dev
```

App runs at `http://localhost:8080`.

```bash
npm run build
npm run typecheck
```

## Contact form

**Send to the kitchen** emails `kellzkitchenjamaicancuisine@gmail.com`. The first submission sends an activation mail to that inbox — open it once. Pickup stays the phone.
